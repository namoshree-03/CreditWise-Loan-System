# 💳 CreditWise Loan System

A Machine Learning project to predict whether a loan application will be approved based on applicant details.

---

## 📌 Project Overview
The **CreditWise Loan System** uses classification algorithms to analyze applicant data and predict loan approval.

---

## ⚙️ Features
- Data Preprocessing (Handling missing values)
- Encoding categorical variables
- Feature Engineering
- Model Training & Evaluation
- Comparison of multiple ML models

---

## 📊 Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes

---

## 🏆 Best Model
**Naive Bayes** performed best based on Precision Score.

---

## 📂 Dataset Features
- Applicant Income
- Credit Score
- Employment Status
- Loan Purpose
- DTI Ratio
- Property Area
- And more...

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Seaborn / Matplotlib
